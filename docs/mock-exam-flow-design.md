# 全真模拟 · 全流程与屏幕布局设计(用户审定版)

修订日期:2026-08-15 · 按用户设计方案重写,取代初版
依据:[雅思口语考试全流程调研](./ielts-exam-flow-research.md)、竞品调研(口语模拟 App,结论见对话记录)

## 一、设计目标

1:1 还原机考视频通话口语 (VCS) 场景:考官出现在屏幕中央、TTS 语音发问、屏幕展示题卡、真实节奏计时。考生对着屏幕开口练习,不打断、不暂停,像真考一样一口气走完 11–14 分钟。

## 二、页面布局

1. **考官在中央,考生画面在右上角**。两者目前先留占位:中央后续接入 AI 虚拟人,右上角后续接入用户摄像头
2. **P2 时**:考官说到「here's your topic」的过渡语时,屏幕上出现 P2 题卡
3. **屏幕固定按键**(底部操作条,全程可见):
   - **出示身份证**:入场阶段,点击后进入 P1
   - **继续**:答完当前问题,进入下一问题 / 下一环节
   - **跳过**:跳过当前问题,进入下一问题
   - **重复**:重读当前问题(重新播放考官语音)
4. **考试全部结束时**:屏幕上汇总各环节时间(入场、P1、P2、P3、总时长)

## 三、配置界面(考试前)

点击「全真模拟」后先进配置界面:

| 配置项 | 选项 | 说明 |
|---|---|---|
| 题库 | 大陆新题 / 大陆旧题 / 非大陆新题(单选) | 界面文案「大陆旧题」= 题库 section「大陆老题」;全真模拟只从所选题库抽题 |
| 声音 | 男 / 女 | 男 = Ryan,女 = Jennifer(沿用练习模式发音人) |

配置完成后点「开始考试」,直接进入考试(无候考阶段)。

## 四、全流程

```
配置界面 → 考官自我介绍(第 N 次考试)→ 出示准考证 → P1
→ P2 过渡段(上题卡 + 1min 倒计时)→ P2 陈述 → P3 过渡(停顿 3s)
→ P3 三问 → 结束语 → 各环节时间汇总
```

### 1. 考官自我介绍 + 出示准考证

- 考官语音:"Good morning / Good afternoon. My name is [考官名]. **This is your [N]th mock speaking test.**" (第 N 次 = 该用户此前全真模拟场次 + 1)
- 随后:考官要求出示准考证(语音:"Can I see your identification, please?")
- 考生点击 **出示身份证** → 进入 P1

### 2. P1(4–5 分钟)

**第一主题**(二选一,固定题库):
- 选项 A "Do you work or are you a student?" → 后续从固定 3 问中**抽 2 个**:
  Why did you choose that job / course?
  Do you enjoy it? Why?
  Is there anything you would like to change about it?
- 选项 B "Let's talk about your hometown. Where is it?" → 后续从固定 3 问中**抽 2 个**:
  What do you like most about it?
  Has it changed much in recent years?
  Would you like to live there in the future?
- 即:第一主题 = 1 个固定首问 + 2 个抽取问题,共 3 问

**第二、三主题**(从配置所选题库 P1 随机抽 2 个主题,每主题 **2–3 个问题**)

每问之后操作:继续 / 跳过 / 重复(见第五节按键语义)

### 3. P2 过渡段

考官语音(说过渡语的同时**题卡上屏**):

> Now I'm going to give you a topic, and I'd like you to talk about it for one to two minutes.
> Before you talk, you'll have one minute to think about what you're going to say.
> You can make some notes if you wish. Do you understand?
> Here's some paper and a pencil for making notes, and here's your topic.

过渡语说完 → 开始 **1 分钟准备倒计时**(硬倒计时)

倒计时结束 → 考官语音:

> All right? Remember you have one to two minutes for this, so don't worry if I stop you.
> I'll tell you when the time is up. Can you start speaking now, please?

考生点击 **继续** → 进入 P2 陈述(2 分钟硬倒计时,题卡常驻屏幕)

### 4. P2 陈述(2 分钟)

- 考生开口连续说,题卡常驻
- 2 分钟到点:倒计时停止,不自动进下一环节;考生可提前说完
- 考生点击 **继续** → 进入 P3 过渡(不点不前进)

### 5. P3(4–5 分钟)

- 考生陈述完 → 点击 **继续** → 考官语音(P3 过渡):

> We've been talking about [P2 话题]. I'd like to discuss with you one or two more general
> questions relating to this topic.

- 过渡语后**停顿 3 秒**
- 从配置所选题库中 **P2 同主题的 P3 题库**抽 3 个问题(**主题与 P2 一致**),逐一提问
- 每问之后操作:继续 / 跳过 / 重复

### 6. 结束

- 考官语音:"This is the end of the speaking test. Thank you."
- 进入时间汇总页:入场 / P1 / P2 准备 / P2 陈述 / P3 / 总时长
- 返回首页按钮

## 五、按键交互语义

| 按键 | 场景 | 行为 |
|---|---|---|
| 出示身份证 | 入场阶段 | 点击后进入 P1(考官开始第一主题) |
| 继续 | 任意提问后 | 进入下一问题;P1 结束后进入 P2 过渡段;P2 陈述后进入 P3 过渡;P3 末问后进入结束语 |
| 跳过 | 任意提问后 | 跳过当前问题,直接进入下一问题(不记录该问题) |
| 重复 | 任意提问后 | 重新播放当前问题语音(字幕保留) |

## 六、屏幕布局(VCS 模拟)

### 通用布局(入场 / P1 / P3)

```
┌──────────────────────────────────────────────┐
│  IELTS SPEAKING · 全真模拟     [考生画面占位] │ ← 右上角(后续接摄像头)
│                                              │
│              ┌──────────────────────┐        │
│              │                      │        │
│              │   [考官占位/AI人]     │        │ ← 中央(后续接 AI 人)
│              │   "Do you prefer     │        │
│              │    sad or happy      │        │ ← 考官字幕(当前问题)
│              │    music?"           │        │
│              └──────────────────────┘        │
│                                              │
│  Part 1 · 3/12 问      第 N 次考试           │ ← 状态条
│  ┌────────────┬────────┬────────┬────────┐  │
│  │  出示身份证  │  继续   │  跳过   │  重复   │  │ ← 底部操作条
│  └────────────┴────────┴────────┴────────┘  │
└──────────────────────────────────────────────┘
```

### P2 布局(过渡 / 准备 / 陈述)

```
┌──────────────────────────────────────────────┐
│  IELTS SPEAKING · 全真模拟     [考生画面占位] │
│                                              │
│  ┌────────────┐   ┌───────────────────────┐  │
│  │            │   │ Describe a tall        │  │
│  │ [考官占位]  │   │ building you like      │  │
│  │ (缩小居左)  │   │                        │  │
│  │            │   │ You should say:        │  │ ← P2 题卡(右主区,纸质感)
│  │            │   │ · What it is used for  │  │
│  └────────────┘   │ · Where it is          │  │
│                   │ · What it looks like   │  │
│                   └───────────────────────┘  │
│                                              │
│  Part 2 · 准备          ⏱ 0:47 / 1:00       │ ← 硬倒计时大字
│  ┌────────────┬────────┬────────┬────────┐  │
│  │  出示身份证  │  继续   │  跳过   │  重复   │  │
│  └────────────┴────────┴────────┴────────┘  │
└──────────────────────────────────────────────┘
```

- 过渡段:题卡随过渡语上屏;考官窗口在过渡语阶段仍居中,进入准备倒计时后缩小至左侧
- 准备阶段:倒计时 + 「可用纸笔记笔记」提示;陈述阶段倒计时变 2:00

## 七、边界情况

| 情况 | 处理 |
|---|---|
| TTS 失败 | 字幕仍显示,「重复」键可重听;连续失败降级浏览器 speechSynthesis |
| 摄像头 / AI 人未接入 | 中央与右上角均为占位,流程不受影响 |
| 中途退出 | 确认弹窗「退出 = 放弃本场」;退出回首页,已抽题目不记录历史 |
| 陈述 2 分钟到点 | 倒计时停止,等待考生点击继续进入 P3 |
| 题库该主题问题不足 | 每主题不足则全出;P3 不足 3 问则全出 |
| 全程无暂停 | 不提供暂停按钮;计时按开始时间计算 |

## 八、与现有系统的关系

- 新增:`static/mock.html` + `mock.js` + 部分 CSS(配置界面 + 考试界面共用一个页面或两个页面,实现时定)
- 后端:新增 `/api/mock/session`(按所选题库生成全场题包:P1 第一主题固定+抽 2、二/三主题随机 2×2-3 问、P2 题卡、P3 3 问)
- **考试次数计数**:新增全真模拟场次记录(history 表加 mode 字段或独立计数表),供「第 N 次考试」语音使用
- 内置固定题库:新增数据文件 `mock_fixed.py`(开场白、出示准考证语、P1 第一主题 A/B 各 1 首问 + 3 备选、P2 过渡语、P2 准备结束语、P3 过渡语、结束语)
- 历史记录:全真模拟抽题记入 history,避重加权与练习模式共用

## 九、决策状态

### 已定(用户拍板)

1. 考官中央、考生右上角,均先占位(后续 AI 人 + 摄像头)
2. 配置界面:题库单选(大陆新题 / 大陆旧题 / 非大陆新题)+ 声音男/女
3. 按键:出示身份证 / 继续 / 跳过 / 重复
4. P1 第一主题:固定首问 + 抽 2 问;第二三主题:随机 2 主题 × 2–3 问
5. P2 过渡语时题卡上屏,说完 1 分钟倒计时,倒计时结束放准备结束语,点继续进陈述
6. P2 无追问;陈述 2 分钟到点停止计时,考生点继续才进 P3(不自动)
7. P3 过渡后停顿 3 秒;**P3 三问与 P2 主题一致**(从 P2 同主题 P3 题库抽)
8. 结束页:各环节时间汇总
9. 无候考阶段,配置后直接开始
10. **第 N 次考试**:按用户历史全真模拟场次统计(新增场次记录)
11. **P2 题卡参与 7 天避重加权**(与练习模式共用历史)
